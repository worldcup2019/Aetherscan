Gemini API key
Powers AI Chat and the AI Overview box. Genuinely free, no card required — get one at aistudio.google.com/apikey. Google changed new keys to authorization keys in September 2026. This app now uses Google's current google-genai client, so new authorization keys work here. Create a new key in AI Studio rather than reusing an old unrestricted Standard key.
Groq API key
Another free option (no card required) for AI Chat and the AI Overview box — tried if neither Gemini nor Claude is set. Uses Groq's fast open-model hosting (currently Llama 3.3 70B). Get a free key at console.groq.com/keys.
Anthropic (Claude) API key
Alternative to Gemini for AI Chat and the AI Overview box — tried after Gemini, before Groq. Pay-as-you-go, get one at console.anthropic.com.
TMDb API key
Powers the Movies tab (posters, ratings, where to watch). Free "Developer" key at themoviedb.org/signup → Settings → API.
Broader web search providers
AetherScan combines several free sources automatically. For broader Bing or Google-style web coverage, add these as Windows environment variables and restart the app: BING_API_KEY, GOOGLE_CSE_API_KEY, and GOOGLE_CSE_ID. Keep provider keys out of screenshots and source files.
PowerShell example: setx BING_API_KEY "your-key".
Google Custom Search needs both an API key and a Programmable Search Engine ID (the cx value).
Leave a field blank and save to clear that key. These keys are stored in your local account database only — they're never sent anywhere except directly to Google/Groq/Anthropic/TMDb when that feature is used.
